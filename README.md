# YS专属训练师

面向大学生立定跳远训练的手机 Web App。用户可以现场拍摄或选择已有的侧面固定机位视频，在浏览器本地完成姿态分析并获得动作改进建议。

## 当前阶段

工程基线与视频输入链路开发中。产品范围与技术决策见：

- [MVP 产品设计文档](./YS专属训练师-MVP产品设计文档.md)
- [MVP 技术方案](./YS专属训练师-MVP技术方案.md)

## 本地开发

```bash
pnpm install
pnpm dev
```

## 质量检查

```bash
pnpm lint
pnpm typecheck
pnpm test
pnpm build
```

本项目为私有项目。引入第三方代码时须保留相应许可证与归属说明。
